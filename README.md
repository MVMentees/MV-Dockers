### build_universe-pickleball

Click on the .zip file, download it into your home directory on your Linux box and unzip it to **build_universe-pickleball** directory

At that point you can run the yaml as explained in the .yaml file or go here and load the github Pickleball project

https://github.com/MVMentees/Pickleball/tree/main
